# pos-extraction-pwa

PWA mobile-first pour saisir une position en degrés, minutes et secondes, prévisualiser le lieu, partager un lien (SMS, WhatsApp, Telegram, Viber) et ouvrir un itinéraire Google Maps depuis la position de l’appareil.

L’historique des recherches est enregistré dans le navigateur (`localStorage`). Pas de publicité, pas d’analytique. La localisation n’est demandée que pour l’itinéraire.

Site : https://tonylapoche.github.io/pos-extraction-pwa/
