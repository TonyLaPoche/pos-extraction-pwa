À propos

Repère sert à partager une position GPS sans publicité. Vous insérez des coordonnées, vous voyez le lieu, vous envoyez un lien.

Tout reste sous votre contrôle. Pas d’analytique, pas de compte, pas d’accès à vos contacts ni à vos photos. L’historique est enregistré seulement sur cet appareil.

La position de l’appareil est demandée uniquement pour créer l’itinéraire : le départ est votre position, l’arrivée est le lieu saisi.

Une application légère, pour transmettre un point GPS sans prise de tête.
